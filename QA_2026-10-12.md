# Admin reliability QA — 2026-10-12

## Scope

Personal calendar editing, shared recent presets (canonical 10 entries, saved time/color/icon), in-flight edits, offline retry, provider replay/live regressions, existing ONSYDE rendering regression tests. No production calendar entries or presets were created or deleted for QA.

## Fixes

- A delayed preset GET (success or failure) no longer overrides a more recent successful save or its status.
- Refresh cooldown now uses the last attempted request, preventing failed refreshes from triggering a continuous request loop.
- Pending presets remain in memory when browser storage is blocked or full, including the case where old disk data is still readable. Leaving the page warns if those memory-only changes are unsaved.

## Three passes

1. Full regression plus initial race/error fixtures: 35 tests passed.
2. Expanded quota and delayed-failure tests plus JS syntax checks: 37 tests passed.
3. Full suite with concurrency 8: 37 tests passed. Live preset GET returned 200 with 10 items; anonymous PUT returned 401. Browser smoke verification follows deployment.

Authenticated writes and conflict retries are tested using isolated mock requests, not test writes to production. These checks do not establish that all possible bugs are absent, nor constitute a full new responsive-layout audit.
